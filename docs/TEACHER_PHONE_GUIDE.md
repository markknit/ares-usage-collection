# ARES Sync - Teacher Installation and Use

ARES Sync helps ARES Education receive scheduled usage summaries from your school's ARES server. After setup, it normally works automatically and does not need daily attention.

## Before you start

Contact your **ARES Advocate or ARES technical-support contact** to obtain your school's one-time installation key. The app may call this an **enrollment code**. It looks like `XXXX-XXXX`, works once, and must not be shared with another school or phone.

You will need:

- an Android phone;
- normal Internet for installation and school enrollment;
- the one-time installation key from your ARES Advocate; and
- ARES or ARES2 within range for the school-network setup.

## Install the app

1. With normal Internet connected, open `https://areseducation.org/phone-setup/` in Chrome.
2. Select **Start phone setup**.
3. Select **Download ARES Sync**.
4. Open `ares-sync.apk` from the download notification or Chrome's Downloads list.
5. If asked, use **Android installer**.
6. If Android says the browser is not allowed to install apps, open **Settings**, enable **Allow from this source**, then return to the installer.
7. If Android recommends an app scan, allow it and continue after it passes.
8. Select **Install**, then **Open**.

Install ARES Sync only from the official ARES Education setup page or with help from your ARES Advocate. Do not turn off Play Protect globally.

## Connect the phone to your school

1. Type part of your school name and select **Find school**.
2. Select the exact school name.
3. Enter the one-time installation key from your ARES Advocate. The app adds the hyphen automatically.
4. Select **Enroll this phone**.
5. Allow ARES Sync to suggest Wi-Fi networks.
6. Allow **Nearby Wi-Fi devices**. Older phones may call this permission **Location**, but ARES Sync does not use it to find your physical location.
7. Approve ARES or ARES2 if Android asks.
8. Allow notifications.

ARES Sync may check both ARES2 and ARES. Wait for setup to finish and return to the main screen.

## How to know setup worked

The main screen should show:

- your correct school;
- the next collection date;
- **Everything is ready. No action required.**
- **Usage data: up to date.**
- a message confirming automatic school Wi-Fi setup is complete.

Show the screen to your ARES Advocate before finishing the installation visit.

## What happens after setup

You do not need to open ARES Sync every day.

On a scheduled collection date, ARES Sync tries to collect a small usage-summary file from the school ARES server. It may briefly connect to ARES or ARES2 for this local step. If Android asks you to approve the school network, approve it.

When normal Internet becomes available later, ARES Sync sends the pending file securely to ARES Education. Normal Internet may be Internet Wi-Fi or mobile data.

ARES Sync does not read your messages, contacts, photos, documents, or browsing history. It transfers the school's ARES usage-summary file.

## Understanding the status

- **Everything is ready. No action required.** - Normal operation.
- **Usage data: up to date.** - Nothing is waiting to send.
- **Waiting to send when Internet is available.** - The file is safely stored; connect to normal Internet and allow time for it to send.
- **Needs attention.** - Connect to normal Internet, open ARES Sync once, and contact your ARES Advocate if the message remains.

## Mobile-data use

The scheduled usage file is separate from the app installer. The system will not accept a usage file larger than 2 MiB, and normal files are expected to be much smaller. Until ARES has measurements from each school, allow up to **5 MB of data per scheduled collection** to cover secure transmission and a possible retry.

With six scheduled collections, **30 MB per year** is a conservative allowance for usage-file delivery. This does not include the initial app download or future app updates. If mobile data is limited, connect the phone to ordinary Internet Wi-Fi when the app says a file is waiting to send.

## Important

- Keep ARES Sync installed.
- Keep notifications allowed.
- Keep your normal Internet Wi-Fi networks saved.
- Do not share an installation key.
- Do not clear the app's storage unless ARES support instructs you to do so.
- A new phone or reinstallation requires a new installation key from your ARES Advocate.

## When to contact your ARES Advocate

Ask for help if:

- you have not received an installation key;
- your school is missing or the wrong school is shown;
- enrollment fails;
- automatic ARES/ARES2 setup does not complete;
- the app repeatedly asks for network approval;
- **needs attention** remains after normal Internet is available; or
- the next collection date appears wrong.
