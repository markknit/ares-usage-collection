ARES Admin Tools

  • ARES Sync App Monitor: This app is intended to be used by School ARES Advocates to automatically capture and upload ARES usage data from their local school ARES server to the ARES support server. After setup it runs automatically in the background to collect ARES usage data on specified dates, and then automatically uploads a very small file to the ARES servers when you are connected to the internet. When you click the link you can download the app file and follow the guided instructions. You can also click here to read/download the ARES Sync User Guide for information regarding installation and usage. If you have any questions or problems please do not hesitate to call your ARES support representative or email at: support@areseducation.org.

  • ARES Usage Monitor: use this to monitor and track the usage of the ARES server by individual modules and by access device.

  • Remote control/support (Anydesk): use this to enable remote support if requested. Please note that this will require the server to be connected to an internet service to work. The support team will give you instructions on how to do this.

  • Anydesk update (remote control/support): use this to reset Anydesk so it can be used for remote access when the server is online. This needs to be executed before Anydesk will work. You can only run it when the server is already online. When the next page opens follow the instructions carefully. First, pick the internet interface presented by number, and enter 'up' to initiate the internet connection. WARNING: Be Patient! This process could take around 30 seconds to execute.***

  • ***** Use the following commands with caution! ******
    They will take about 60 seconds to take effect. Make sure all work is saved and all users are offline before using.
  • Reboot server: use this (carefully) to reboot the server if you encounter a problem. Please warn users in advance, as this will end all sessions immediately.
  • Shutdown Server: use this (carefully) to shutdown the server if it will not be used for an extended period. Please warn users in advance, as this will end all sessions immediately. Note: this will take one minute to execute.
