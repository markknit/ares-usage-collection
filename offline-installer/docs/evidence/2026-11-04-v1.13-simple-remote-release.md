## Resulting support workflow

Optional activation enables Tailscale SSH and operator ares automatically. It
keeps TigerVNC on loopback and saves a persistent private Serve TCP/5901 forward
to 127.0.0.1:5901. The technician connects the Windows Tailscale app, opens a saved
RealVNC/TigerVNC connection at the school's tailnet address and enters the VNC
password. No routine PowerShell tunnel is required. Browser SSH has its own
ephemeral connection and does not connect Windows desktop applications.

Existing matching routes are reused; unrelated routes and conflicting/public
port-5901 handlers are preserved. If private forwarding fails after TigerVNC is
healthy, SSH and TigerVNC remain running and activation reports partial failure.
Actual coordination health is printed on failure. Ordinary retries never force
Tailscale reauthentication or clear an AnyDesk profile.

First-school AnyDesk setup replaces the cloned ID once. A completed same-school
reinstall preserves the ID/password. The reusable base must predate school
personalization; explicit reassignment is documented separately.
