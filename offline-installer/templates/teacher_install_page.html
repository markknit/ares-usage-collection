Install ARES Sync

You can download and install the teacher app directly from this ARES school server without Internet access. Enrollment may require normal Internet or mobile data to verify your one-time code.

⬇ Download ARES Sync for Android
Direct address: http://ares.local/downloads/ares-sync.apk

Installation steps

  1. Stay connected to the school's ARES network.
  2. Tap Download ARES Sync for Android above.
  3. Open the downloaded APK. If Android asks for permission to install apps from this browser or file manager, allow it for this installation.
  4. Install and open ARES Sync.
  5. When prompted, use the installation/enrollment code supplied by your ARES technician or ARES Advocate. If enrollment needs the central ARES service, enable normal Internet or mobile data for that step.
Keep your code private. If the code is rejected or the app cannot find the school server, contact your ARES support person before changing network settings.
