Set up this Android phone

ARES Sync collects scheduled usage data from your school's ARES server and sends it securely to ARES Education when normal internet access is available.

Start phone setup

What happens after setup

1. Mostly automatic

ARES Sync keeps the school assignment and collection schedule on the phone. No daily action is required.

2. School collection

When a collection is due, ARES Sync can reach ARES or ARES2 for the school-server request even when the phone normally uses another Wi-Fi network for internet.

3. Automatic submission

When normal internet access is available, pending usage data is submitted automatically in the background.

What you need

  • An Android phone with normal internet access for first-time setup.
  • The one-time enrollment code supplied by ARES Education for your school.
  • Access to at least one school Wi-Fi network named ARES or ARES2.
