Install ARES Sync

One app for school usage collection and automatic submission

Before you begin

Use an Android phone with normal internet access. You will also need the one-time enrollment code supplied by ARES staff for your school.

1

Download ARES Sync

Tap the button below to download the ARES Sync Android app.

Download ARES Sync

Android may ask you to allow installation from this browser. Approve that request only for this ARES installation, then install the app.

2

Open ARES Sync and enroll this phone

Keep the phone connected to the internet. Search for your school in ARES Sync, select the correct school, enter the one-time enrollment code supplied by ARES staff, and complete enrollment.

The enrollment code is used once. Do not share it with other schools.

3

Allow notifications

If Android asks for permission to show notifications, choose Allow. ARES Sync uses notifications to remind you when a collection is due.

Regular use

  1. When ARES Sync says a collection is due, open the app and tap the button to connect to the school ARES network.
  2. In Android's Wi-Fi screen, connect to ARES2 or ARES.
  3. Return to ARES Sync. The app downloads the usage report from the school server.
  4. When the app confirms the collection is complete, you may leave ARES Sync.
  5. Reconnect the phone to normal internet whenever it is available. ARES Sync sends the pending report automatically in the background.

You do not need to keep ARES Sync open while waiting for internet.

How to know it worked

After internet access returns, opening ARES Sync should show Central upload: no pending files. If a file is still pending, leave the phone connected to the internet and check again later. If the app shows a blocked or error status, contact ARES support.

Important

Do not uninstall ARES Sync after enrollment unless ARES staff asks you to. Uninstalling removes the phone's enrollment and requires a new one-time enrollment code.
