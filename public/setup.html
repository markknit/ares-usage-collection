Install ARES Sync

Set up this phone once, then ARES Sync works mostly automatically

Before you begin

You need an Android phone with normal internet access and the one-time enrollment code supplied by ARES Education for your school.

1

Download ARES Sync

Use this ARES Education page on the phone, then tap the button below.

Download ARES Sync

Only install ARES Sync from the official ARES Education setup page or from an ARES technician.

2

Allow Android to install the app

Because ARES Sync is installed directly by ARES Education rather than from Google Play during this rollout, Android may show a security warning.

If Android says this source is not allowed:
  1. Tap Settings or Allow from this source.
  2. Allow installation for the browser or Files app you used to open this ARES APK.
  3. Go back to the ARES Sync installer and tap Install.

If Android or Play Protect shows another warning with a hidden More details or similar option, open it and choose Install anyway only when the APK was downloaded from this official ARES page. Wording varies by phone.

Do not turn off Play Protect globally. After installation, you may turn off “Allow from this source” again. If Android does not offer a safe install option, stop and contact ARES support.

3

Open ARES Sync and enroll this phone

Keep the phone connected to normal internet. In ARES Sync:

  1. Search for your school.
  2. Select the exact school name.
  3. Enter the one-time enrollment code supplied by ARES staff.
  4. Tap Enroll this phone.

The enrollment code is school-specific and is used once. Do not share it with another school.

4

Allow notifications

If Android asks whether ARES Sync may send notifications, choose Allow. Notifications are used only when the app needs attention for a scheduled collection.

After setup

Normal state: ARES Sync should show your school, the next collection date, and Everything is ready. No action required.

You do not need to open ARES Sync every day. When a collection becomes due, the app first tries to collect silently if the phone can already reach the school ARES server.

If the school network is not available, ARES Sync will ask you to connect the phone to ARES2 or ARES. Return to ARES Sync after choosing the school Wi-Fi. The app then collects the usage report automatically.

When normal internet access later returns, ARES Sync sends any pending usage report automatically in the background.

How to know it worked

Open ARES Sync and look at the collection and usage-data cards:

  • Usage data: up to date means nothing is waiting to be sent.
  • Waiting to send when Internet is available means the collection is safely stored on the phone and will upload later.
  • If the app says an upload needs attention, connect to normal internet, reopen ARES Sync, and contact ARES support if the message remains.

Important

  • Do not uninstall ARES Sync after enrollment unless ARES staff asks you to. Uninstalling removes the phone's enrollment.
  • Do not share enrollment codes between schools.
  • ARES Sync does not require Round Sync, Automate, MacroDroid, Google Drive setup, or manual file handling.
