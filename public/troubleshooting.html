Troubleshooting

Phone setup and usage submission

Round Sync does not run in the background

Set battery use to Unrestricted, permit background data, and enable autostart if the phone provides that setting. Then run the ARES task manually once.

The report does not download on ARES Wi-Fi

Confirm the phone joined the exact SSID shown on the school setup page. Open the local server address in Chrome. If it does not load, reconnect to the Wi-Fi and choose to remain connected even though it has no internet.

The report remains on the phone

This normally means the phone has not yet reached OneDrive. Disconnect from the offline ARES Wi-Fi, enable cellular data or internet Wi-Fi, and manually run the Round Sync task.

Reminders continue after collection

Confirm a valid report exists in the ARES usage folder or has been moved by Round Sync. Open MacroDroid and verify the imported ARES macros are enabled.

Reinstall

Return to the school-specific setup QR code and repeat the import steps. Do not create a second Round Sync task; replace or remove the old ARES task first.
